# classics-guide · 三家经典导读

一个陪读儒释道经典的 Agent Skill：三十次弹性课表、二十九篇精讲、内置全本原文库，还能借圣贤的眼睛看你自己的处境——"孔子会怎么看我这件事"。

目标是一句话：**读懂一句，用上一天。** 不堆知识，不灌鸡汤，不装神弄鬼。

## 有什么

- **三十次课表**（`references/curriculum.md`）：按次不按天，每次约 15 分钟，固定流程"回顾践行 → 检索复习 → 新篇四步 → 定一条践行"。断档不补、不批评，回来接着走。
- **间隔复习**：新学篇目排在第 +1 / +3 / +7 次各复习一次，先提问后补充，答不上就重排。
- **二十九篇精讲**（`references/ru.md` / `dao.md` / `fo.md`）：儒 11、道 12、释 6，四步讲法——原文 → 白话 → 义理 → 今天怎么用。
- **全本原文库**（`references/texts/`，23 个文件）：论语、孟子、大学、中庸、道德经、庄子、周易、金刚经、法华经、普贤行愿品、坛经、传习录、孝经、孙子兵法、菜根谭、小窗幽记等全本，另收毛泽东六篇与曾国藩家书三篇。书目以 `references/CATALOG.md` 为准。
- **圣贤对谈**（`references/sages.md` / `sage-dialogues.md`）：孔子、孟子、老子、庄子、佛陀、慧能、王阳明、曾国藩、苏轼、范仲淹、马克思、毛泽东、周恩来十三位"为人内核"卡片；问"某某会怎么看我这件事"时按"思想公理 → 处境映射 → 一句反问 → 一步行动"推演，所有回答明确标注**拟答**，不冒充原话。
- **进度账本**：真正的进度写在你的工作区 `.dsh/classics-progress.md`（仓库里的 `progress.md` 只是模板）；多学习者共用时先过"主人核对"，各记各的账。

## 安装

需要支持 Agent Skills（SKILL.md 格式）的环境，如 [DSH](https://github.com/deepseek-ai) 或 Qoder。

**DSH**：整目录克隆到技能目录（必须包含 `references/`，只拷 SKILL.md 会缺原文库）：

```bash
git clone https://github.com/<你的用户名>/classics-guide.git ~/.dsh/skills/classics-guide
```

**Qoder**：把本目录打包成 ZIP，扩展 → Skills → Add Skills → Upload Skill 导入；或整目录放到你的技能库。

## 用法

- 说 `/classics-guide`、"开始我的读经课"或"继续我的读经课"进入上课模式。
- 问"孔子会怎么看我这件事"进入对谈模式（先弄清处境，再给拟答与一步行动）。
- 点名某一篇可以跳出课表直接读。

## 设计原则

- **引文零编造**：只从内置原文库或用户提供的原文取引文；两处都没有就明说没有，绝不编"某经某章说过"。
- **原文与解读分层**：原文照录、白话是翻译、义理是解读，不把某一家注解说成唯一正解。
- **读取预算**：一次课最多读 1 个精讲文件 + 1 段全本原文，大文件先检索后读局部，不整本读入。
- **尊重立场**：不评判信仰，不做吉凶预言；用户从实践论、矛盾论看问题可以顺着对照，不强行祛魅也不强行宗教化。
- **心理边界**：用户表露严重困扰时先照顾人，不替代医疗与心理治疗。
